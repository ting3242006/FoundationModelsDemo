▲ iOS TECH SHARING

③ GUIDED GENERATION ★ 最強的部分

不回傳字串，直接回傳 Swift 型別

@Generable(representNilExplicitlyInGeneratedContent: true)
struct EventDraft {
    @Guide(description: "簡短事件標題")
    var title: String
    var date: DateIntent
    @Guide(description: "只說晚上沒說幾點 → null",
           .range(0...23))
    var hour: Int?
    @Guide(.range(1...480)) var durationMinutes: Int
    var attendeeQuery: String?
}

生成時就被限制只能產出合法格式
（constrained decoding）

不會少括號、不用 JSONDecoder、不會 parse 失敗

@Guide 同時是說明書和限制：範圍、選項、語意

MessyNote/Models/EventDraft.swift（精簡）

這是 Foundation Models 和一般 LLM API 最大的差別。一般 LLM 回字串，你要自己 parse JSON，可能少括號、可能多一句廢話。這裡在生成時就被約束，只能產出符合型別的結果。@Guide 一方面是給模型看的說明，一方面是硬限制，例如 hour 只能 0 到 23。注意 hour 是 Optional：使用者只說「晚上」沒說幾點，模型必須回 null，而不是亂猜。
