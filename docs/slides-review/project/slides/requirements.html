if #available(iOS 26.0, *),
   SystemLanguageModel.default
      .isAvailable {
    showAIFeature()
} else {
    hideAIFeature()
    // 錦上添花，不是必要路徑
}

Apple 官方的裝置與語系清單可能變動，以 runtime 檢查為準

五個條件缺一個就用不了，所以一定要 runtime 檢查、一定要有 fallback。設計功能時就要假設很多人看不到它，它應該是加分項，不是主流程。語系這點特別注意：中文支援狀況要以 supportsLocale 實測為準。
