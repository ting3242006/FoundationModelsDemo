④ STREAMING

串流的是逐步成形的結構，不是 token

for try await snapshot in session.streamResponse(
    to: prompt, generating: EventDraft.self,
    options: GenerationOptions(samplingMode: .greedy, maximumResponseTokens: 1024)) {
    onPartial(snapshot.content)       // EventDraft.PartiallyGenerated，欄位全是 Optional
    final = snapshot.rawContent
}
return try EventDraft(final)      // 結束後才驗證成完整型別

01

欄位出現順序不保證
UI 只畫已經有的欄位

02

partial 結果不能存
只有完整驗證過的才能進下一步

03

.greedy 讓抽取更穩定
同樣輸入、同樣輸出

MessyNote/AI/FoundationModelService.swift

streamResponse 每次給你的是一個快照，型別是 PartiallyGenerated——所有欄位都變成 Optional，隨生成逐步填上。UI 可以邊生成邊顯示，但記住三件事：欄位順序不保證；partial 不能存；做資訊抽取時用 greedy sampling，結果比較穩定。MessyNote 沒有用假的 timer 動畫，畫面上看到的就是真實的 snapshot。
