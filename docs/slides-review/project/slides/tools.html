⑤ TOOL CALLING

模型知識不夠，就讓它呼叫你的程式

struct FindContactTool: Tool {
    let name = "findContact"
    let description = "Read minimal contact candidates…
        Never select among multiple candidates."
    @Generable struct Arguments {
        var query: String
        var draftID: String
    }
    func call(arguments: Arguments) async throws -> String {
        try await ledger.find(query: arguments.query, …)
    }
}

模型自己判斷要不要呼叫，參數也是 @Generable

回傳值會丟回給模型，整合進回答

MessyNote 的工具全部唯讀；寫入行事曆永遠走人工確認

MessyNote/AI/FindContactTool.swift

Tool 是補足小模型知識不足的方法：它不知道你的聯絡人和行事曆，但可以呼叫工具去查。實作 Tool protocol：name、description、@Generable 的 Arguments、call 方法。注意 description 裡直接寫了「多個候選時不准替使用者選」——工具描述也是 prompt 的一部分。MessyNote 刻意讓所有工具只能讀不能寫。
