⑥ iOS 27 新增

用 Profile 精準控制工具呼叫次數

extension SessionPropertyValues {
    @SessionPropertyEntry var toolCalls: Int = 0
}
struct SingleToolReviewProfile<T: Tool>:
        LanguageModelSession.DynamicProfile {
    @SessionProperty(\.toolCalls) var toolCalls
    let tool: T
    var body: some LanguageModelSession.DynamicProfile {
        Profile { tool }
        .toolCallingMode(toolCalls < 1 ? .required : .disallowed)
        .onToolCall { toolCalls += 1 }
    }
}

第一次必須呼叫工具，之後禁止再呼叫

避免 required 模式無限重複呼叫

建立方式：
LanguageModelSession(profile:)

MessyNote/AI/SingleToolReviewProfile.swift · 需要 iOS 27 SDK

這頁是 iOS 27 才有的 API，iOS 26 上不能用。DynamicProfile 把 session 的設定寫成一個宣告式的 body，像 SwiftUI。SessionProperty 是 session 內的狀態，這裡拿來計數：第一次一定要呼叫工具（required），呼叫過一次之後就禁止（disallowed）。Apple 官方範例第二階段是 allowed，MessyNote 改成 disallowed，避免模型一直重複查。
