▲ iOS TECH SHARING

⚠ 上線前一定會踩到的五件事

地雷說明對策
Context 很小輸入＋輸出合計約 4096 tokens短 prompt、窄型別；超過就重置
Guardrails敏感內容會被 Apple 擋下處理 guardrailViolation / refusal
Prompt injection使用者輸入可能夾帶指令instructions 明講「輸入是資料」
不能並行同一 session 回應中不能再送檢查 isResponding，或開新 session
結果會錯小模型會誤判、會猜Swift 驗證＋使用者確認

MessyNote（iOS 27 SDK）的錯誤型別為 LanguageModelError：contextSizeExceeded · guardrailViolation · refusal · timeout · rateLimited

五個地雷。Context window 很小，約 4096 tokens，包含輸入和輸出，所以 prompt 要短、型別要窄。Guardrails 是 Apple 內建的安全過濾，要處理對應錯誤。Prompt injection 的防法是規則寫在 instructions，並明講使用者輸入只是資料。同一個 session 一次只能處理一個請求。最後，結果一定可能錯，所以要 Swift 驗證加使用者確認。錯誤型別的名稱：MessyNote 用 iOS 27 SDK，處理的是 LanguageModelError；iOS 26 時期的寫法是 LanguageModelSession.GenerationError，升版時要注意。
