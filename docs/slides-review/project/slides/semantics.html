型別能保證 hour 在 0–23，卻無法保證它真的是使用者說的那個時間。
模型負責理解，計算和驗證交給 Swift，最後交給人確認。

Guided Generation 的盲點：結構一定對，內容不一定對。模型可能把星期幾算錯、把「晚上」猜成 19 點。MessyNote 的做法是讓模型只輸出「語意」——相對幾天、下週星期幾、明確的年月日——真正的日期由 Swift 的 DateResolver 計算，它會拒絕不存在的日期和 DST 不存在的時刻。這是整個 demo 最值得帶走的設計原則。
