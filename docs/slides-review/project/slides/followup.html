「改成四點半」只改時間，其他不動

@Generable struct EventRevision {
    var changes: [EventField]  // 白名單
    var values: EventDraft
}
@Generable enum EventField {
    case title, date, time, duration,
         location, attendee, notes, reminder
}

漏抽時間？再用窄型 ClockCompletion 補一次

使用者說「好，那改成 16:30」時，模型不是重新產生整份草稿，而是產生 EventRevision：changes 列出要改哪些欄位，values 是新值。Swift 只套用 changes 裡的欄位，所以日期、地點、提醒都會保留。如果模型漏掉時間，再開一個全新的小 session，只問 hour 和 minute 兩個欄位。窄型別、小任務，正確率就高很多。
