Q&A.

✓ 適合

功能是錦上添花

任務是理解、抽取、分類

重視隱私、需要離線、不想付 API 費用

✗ 不適合

功能必須人人都能用

需要知識、複雜推理或長文本

錯了就會出事、又沒有人確認

想試試：Xcode 的 #Playground 可以直接在編輯器裡試 prompt

收尾用一個判斷準則：如果功能是加分項、任務是理解或抽取、又重視隱私，Foundation Models 是很好的選擇；如果功能每個人都要能用、需要知識或推理，還是用雲端 LLM 或不用 AI。想試的話，Xcode 的 #Playground macro 可以直接在編輯器裡試 prompt，不用跑 App。
